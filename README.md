## Overview

This repository provides comprehensive documentation for change management processes using [MkDocs](https://www.mkdocs.org/) with the popular [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) theme. It is intended as a centralized resource for best practices, guidelines, and procedures related to change management in IT and business environments.

## Features

- **Built with MkDocs:** Easily maintain and extend documentation using Markdown.
- **Material Theme:** Clean, modern, and responsive design for improved readability.
- **Open Source:** Licensed under GNU GPL v3.0.
- **GitHub Pages:** Documentation is published and accessible at:  
  [https://omkarg419.github.io/change-management-documentation/](https://omkarg419.github.io/change-management-documentation/)
- **Topics Covered:**  
  - Change management principles  
  - Process flows and templates  
  - Roles and responsibilities  
  - Risk assessment and mitigation  
  - Example change requests and documentation standards
